# CANVAS DE PRODUCTO - APP RECETAS INTELIGENTES

## 1. Visión del Producto
Aplicación web responsiva que permite a los usuarios ingresar ingredientes disponibles (manual o foto) y recibir recetas personalizadas generadas con IA.

## 2. Objetivo
Reducir desperdicio de comida y facilitar decisiones de cocina.

## 3. Funcionalidades Clave
- Registro/Login de usuarios
- Ingreso manual de ingredientes
- Captura de foto de ingredientes (IA)
- Generación de recetas con OpenAI
- Historial de recetas
- Guardado de favoritos

## 4. Reglas del Sistema
- Toda nueva funcionalidad debe validarse contra este documento
- No romper funcionalidades existentes
- Mantener consistencia UX/UI
